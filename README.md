Сначала заходим в терминал и пишем "pip install -r requirements.txt". Далее в main.py заменяем api_id и api_hash на свои.
В chat_list вписать айди чатов или юзернеймы через @, в messages добавить сообщения которые нужно отправлять, разделять абзацем.
Также можно менять интервал между отправкой сообщения в разные чаты (interval) и между сменой самих сообщений (cooldown), значения указаны в секундах.
